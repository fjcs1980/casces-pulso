Comunicación simple

¿Algo impide continuar? Abre el entregable y usa «Reportar bloqueo». El motivo aparecerá en Vista general de este navegador, donde se podrá registrar una decisión. Cuando el impedimento desaparezca, puedes indicar «Ya puedo continuar» desde Mi trabajo. Tus acciones alimentan la línea de tiempo automáticamente.

Demo sin cuentas ni permisos reales. Ambas vistas usan los mismos datos de este navegador (localStorage), no comparten información entre dispositivos. No utilizar con datos sensibles ni para operación productiva.
